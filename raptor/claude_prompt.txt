클로드, 현재 RAPTOR Vercel 프로덕션 환경과 Render 백엔드 연동 중 "서버와 연결할 수 없습니다"라는 단일 에러 메시지가 401, 403, 500 에러를 모두 은폐하고 있어 정상적인 트러블슈팅이 불가능하다. 

VIBE 프레임워크 R&R에 따라 너에게 파일 직접 수정 권한은 부여하지 않는다. 다음 사항을 기반으로 분석을 수행하고, 교체가 필요한 정확한 코드 스니펫(Snippet)만 제시하라.

[핵심 전제]
1. BYOK 보안 원칙에 따라 로그아웃 시 로컬 스토리지의 KIE API 키가 삭제되는 현재 로직은 필수 보안 사항이므로 절대 수정하지 마라.

[프론트엔드 조치: AuthDashboard.tsx 및 api-client.ts]
1. fetch 응답의 HTTP status 코드를 기반으로 에러를 파싱하는 로직을 제안하라.
2. 401 (Unauthorized) 에러 발생 시 "API 키가 누락되었거나 만료되었습니다. 우측 상단에 API 키를 다시 입력해 주세요."라는 명시적인 UI 알림을 표시하는 스니펫을 작성하라.
3. 403 (Forbidden/CSRF) 에러와 500 (Internal Server Error) 에러 역시 상태 코드에 맞게 분기하여 사용자에게 원인을 출력하는 스니펫을 포함하라.

[백엔드 조치: main.py]
1. enforce_user_fifo_limit 로직에서 과거 레거시 프로젝트(10개 초과분)를 삭제할 때 발생하는 데이터베이스 무결성 에러를 try-except로 방어하는 스니펫을 작성하라.
2. 삭제 쿼리 실패가 발생하더라도 500 에러로 전체 API 응답을 중단시키지 말고, 로깅 후 신규 프로젝트 생성이 정상 진행되도록 재시도(Retry) 또는 패스하는 로직을 제안하라.
